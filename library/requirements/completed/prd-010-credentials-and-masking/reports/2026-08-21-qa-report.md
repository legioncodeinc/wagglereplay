## Summary

The prd-010 implementation is blocked by one Critical privacy gap affecting AC4 and the image-bearing part of AC5: capture-derived QA frames are extracted and persisted directly from the raw recording without a redaction box, then those same PNGs can be attached to a pre-draft provider request. Schema validation, names-only CLI output, callback-only act-time resolution, RFC 6238 TOTP, Studio-to-subsequent-recording selector marking, fixed placeholder events, replay video/screenshot overlays, and shared text scrubbing are present and tested, but the plan's screenshot-before-storage guarantee is not implemented. Re-run security-worker-bee after remediation, then re-run this quality audit.

## Critical Issues (must fix)

- [ ] **Marked capture frames are persisted unredacted and can cross the vision-provider boundary (AC4, AC5)**, `packages/ingest/src/frames/extract-keyframes.ts:74-101`; `packages/ingest/src/pipeline/run-ingest.ts:73-125`; `packages/ingest/src/predraft/run-predraft.ts:79-93`; `library/requirements/backlog/prd-010-credentials-and-masking/qa/canary-leak-test.md:6`

  The marking path changes telemetry to a fixed placeholder, but it does not change the pixels recorded by the tab. Ingest invokes ffmpeg against the raw recording and writes each requested PNG directly to the project, with no credential rect or redaction filter. `runIngest` then passes those persisted assets to pre-draft, whose image loader base64-encodes the PNGs unchanged; the shared scrubber only processes strings. The canary log claims video frames and screenshots were covered by replay unit tests, but those tests only prove DOM overlay ordering and structured-text scrubbing, and the real replay E2E contains no credential-bound fill. Suggested: add a rect-bearing marked-input capture contract and either install an opaque capture overlay before the value is visible or apply deterministic redaction to every flagged extracted frame before writing it; then add a real credential canary E2E that asserts the stored PNG and provider-bound image are redacted and no canary appears in IR, reports, errors, or text artifacts.

  ```ts
  const argv = [
    '-y', '-i', videoPath, '-ss', toSeekArg(request.relMs),
    '-frames:v', '1', absolutePath,
  ];
  await runner(argv);
  ```
